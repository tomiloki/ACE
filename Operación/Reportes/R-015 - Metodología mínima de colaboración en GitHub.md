# Metodología mínima de colaboración en GitHub

## Reporte del ejecutor

Tomás acordó una metodología proporcional: cada integrante trabaja en una rama activa por módulo o frente, y una pull request integra ese resultado cuando termina o cuando otro frente lo necesita. Los cambios acotados de backlog, borradores y documentación sin trabajo concurrente pueden publicarse directamente en `main`.

La guía vigente está en [[Colaboración en GitHub]]. No se agregaron automatizaciones, protecciones de rama, plantillas ni CI.

## Pendiente

La propuesta debe probarse con la primera pull request de un módulo antes de considerarse definitiva. Este reporte conserva esa validación y la eventual revisión del equipo.
