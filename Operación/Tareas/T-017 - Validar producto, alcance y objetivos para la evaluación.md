# Validar producto, alcance y objetivos para la evaluación

Acordar la definición de ACE que usará la primera evaluación y comprobar que producto, alcance, objetivos y arquitectura preliminar cuentan una historia coherente.

## Incluye

- Validar la descripción del problema y de la solución.
- Revisar alcance inicial y fuera de alcance.
- Aprobar o corregir el objetivo general y los objetivos específicos.
- Identificar contradicciones que deban resolverse antes del informe o la presentación.

## Criterio de aceptación

- El equipo dispone de una definición de producto y objetivos aprobados para la evaluación.
- Las contradicciones relevantes quedaron resueltas o declaradas explícitamente como asuntos abiertos.
