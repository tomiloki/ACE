	# Borradores

Espacio compartido para versionar ideas, propuestas, respuestas, alternativas y trabajo incompleto que todavía no forma parte del estado oficial de ACE.

Nada dentro de esta carpeta crea por sí solo una tarea, decisión, compromiso, prioridad ni fuente de verdad. No existe una plantilla obligatoria.

Cuando el equipo acepta algo, se sintetiza en su destino canónico: tarea, decisión, documentación o reporte. El historial de Git conserva el borrador aunque después se elimine.

Los agentes consultan esta carpeta solamente cuando el usuario la menciona, un artefacto vigente la enlaza o el asunto activo la vuelve relevante.
